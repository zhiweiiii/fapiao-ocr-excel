发票OCR识别工具 —— Windows 使用说明
====================================

一、运行环境要求
  1. Windows 10 / 11（64 位）
  2. 已安装 64 位 Python 3.9 ~ 3.13（推荐 3.12）
     下载地址：https://www.python.org/downloads/windows/
     安装时务必勾选 "Add python.exe to PATH"
  3. 首次运行需要联网（下载依赖，几百 MB），之后可离线使用
  4. 至少 3GB 可用磁盘空间

二、使用方法
  1. 把压缩包解压到【纯英文路径】下，例如 D:\fapiao-ocr
     （路径中有中文可能导致 OCR 模型加载失败）
  2. 双击 start.bat
     - 第一次运行会自动安装依赖，需要 5~20 分钟，请耐心等待
     - 之后每次双击，几十秒内即可启动
  3. 启动完成后会自动打开浏览器；如果没有自动打开，
     请手动访问：http://127.0.0.1:39417/fapiao
  4. 在网页中上传发票（支持 jpg / png / bmp / pdf，可多选），
     识别完成后下载 Excel
  5. 使用期间不要关闭黑色命令行窗口；关闭窗口即退出程序

三、常见问题
  Q: 提示"未找到可用的 Python"？
  A: 按上面的地址安装 Python，安装时勾选 "Add python.exe to PATH"，
     装好后重新双击 start.bat。

  Q: 依赖安装失败？
  A: 检查网络后重新双击 start.bat；仍失败可删除本目录下的 .venv 文件夹再试。
     默认使用阿里云 pip 镜像，如需更换，可在运行前设置环境变量 PIP_INDEX_URL。

  Q: 端口 39417 被占用？
  A: 用记事本打开 start.bat，把 set "PORT=39417" 改成其他端口（如 39418）。

  Q: 识别速度？
  A: 使用 CPU 识别，一张发票约 5~15 秒，取决于电脑性能。

  Q: 识别结果不准？
  A: 优先上传税务系统下载的电子发票 PDF：程序直接读取 PDF 里的文字，准确且很快。
     扫描件、图片需要 OCR 识别；手机拍照（尤其是倾斜、旋转的）效果较差。
     导出的 Excel「发票主表」最后一列「复核提示」会写明金额对不上、字段缺失
     等问题，有提示的发票请人工核对。
